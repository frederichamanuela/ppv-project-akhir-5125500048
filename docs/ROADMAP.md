# Roadmap

| Pertemuan | Target | Fitur dari charter | Bukti selesai |
|---|---|---|---|
| P10 | Debug minimal 2 bug nyata, memakai cabang dan merge | Kelola tugas (Must), Kalender dan pengingat (Must) | 2 cabang `fix/...` di-merge ke `main`, riwayat commit terlihat |
| P11 | Pecah kode menjadi minimal 3 modul ES | Kelola tugas, Kalender dan pengingat, Notes (Should) | `src/` berisi ≥ 3 modul `import`/`export`, aplikasi tetap jalan |
| P12 | Komponen reusable, penyimpanan data aman, README dan CHANGELOG, tag `v0.x` | Data tetap setelah refresh (Must) | Uji refresh 5 kali lolos, tag `v0.1` |
| P13 | Konsep produk (Tugas 7) | Semua fitur MVP, Won't dijelaskan alasannya | Dokumen konsep sesuai charter |
| P14 | Demo akhir | Timer Pomodoro (Could) bila waktu cukup | Demo alur utama ≤ 2 menit tanpa bantuan |
