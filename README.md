# TugasIde
Pelacak tugas kuliah dengan kalender, pengingat deadline, catatan, whiteboard, dan timer Pomodoro, dibuat untuk mahasiswa D3 MM B.

**Masalah:** Mahasiswa kesulitan memantau deadline tugas karena tugas tiap mata kuliah diumumkan lewat kanal yang berbeda-beda, sehingga tidak ada satu daftar yang menyatukannya dan tugas sering terlewat.


1. Unduh atau `git clone` repositori ini.
2. Buka `index.html` dengan klik dua kali (atau Live Server di VS Code).
3. Tidak perlu instal apa pun. Koneksi internet hanya dipakai untuk memuat font dan Bootstrap dari CDN.

## Struktur
- `index.html` : halaman utama
- `src/` : kode JavaScript tambahan (wrapper pustaka UI)
- `assets/` : logo dan audio
- `docs/` : dokumen perencanaan
